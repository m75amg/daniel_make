📌 이번 Quest에서는

스마트 미러에 음성 인식 기능을 통합하는 작업을 진행했습니다.

주요 작업 내용
  • Google Speech-to-Text API 연동
  • 한국어 음성 명령어 파싱 로직 구현
  • Wake Word 감지 기능 추가 ("거울아" 호출어 설정)
  • 마이크 배치 최적화 및 노이즈 캔슬링
기술 스택
  • Google Cloud Speech API
  • Python 3.9 / PyAudio
  • 라즈베리파이 4B (4GB RAM)
✅ 완료된 작업
  • Google Cloud 프로젝트 생성 및 API 키 발급
  • Speech-to-Text API 연동 및 테스트
  • 실시간 오디오 스트리밍 파이프라인 구축
  • Wake Word 감지 알고리즘 구현
  • 한국어 명령어 인식률 테스트 (목표: 90% 이상) ✅ 달성
  • 마이크 위치 최적화 (거울 상단 중앙 배치)
  • 노이즈 필터링 구현 (배경 소음 제거)
  • 응답 속도 최적화 (평균 0.8초 내)
🔧 기술 상세 내용

Google Cloud Speech API를 활용하여 실시간 한국어 음성 인식 시스템을 구축했습니다.

구현 세부 사항
  • Streaming Recognition API를 이용한 실시간 처리
  • PyAudio로 마이크 입력 스트리밍 파이프라인 구성
  • WebRTC VAD 라이브러리로 음성 감지 구현
  • Porcupine으로 "거울아" Wake Word 감지 구현
🗂️ 단계별 진행 상황
  • 1단계: Google Cloud 환경 설정 및 API 키 발급 완료
  • 2단계: 기본 음성 인식 테스트 완료 (정확도 72%)
  • 3단계: Wake Word 시스템 구현 완료
  • 4단계: 노이즈 캔슬링 적용 후 정확도 향상 (90% 달성)
  • 5단계: 마이크 위치 최적화 및 최종 테스트 완료
🛠️ 사용 도구
  • IDE: VS Code + Python Extension
  • 음성처리: Google Cloud Speech-to-Text API
  • 오디오: PyAudio, SpeechRecognition
  • Wake Word: Porcupine (Picovoice)
  • 하드웨어: Raspberry Pi 4B, USB Microphone
