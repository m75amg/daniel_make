프로젝트 소개

이 프로젝트는 라즈베리파이 4를 메인 컨트롤러로 사용하는 자율주행 로봇입니다. OpenCV 라이브러리를 활용하여 실시간 영상 처리를 통한 장애물 인식과 경로 계획을 수행합니다.

주요 기능
  • ✓실시간 장애물 감지 및 회피
  • ✓A* 알고리즘을 활용한 최적 경로 탐색
  • ✓음성 명령을 통한 목적지 설정
  • ✓웹 인터페이스를 통한 원격 모니터링
사용 기술
Python OpenCV TensorFlow Raspberry Pi Arduino ROS

제작 과정

1. 하드웨어 조립

로봇 섀시에 라즈베리파이, 모터 드라이버, 배터리를 장착하고 배선을 정리했습니다.

2. 센서 통합

초음파 센서와 카메라 모듈을 연결하고 테스트했습니다.

3. 소프트웨어 개발

장애물 인식 알고리즘과 경로 계획 시스템을 구현했습니다.
