📌 자료 소개

자주 사용하는 ESP32 센서 연동 회로도를 Fritzing 파일로 정리했습니다.

DHT22, BMP280, MPU6050, HC-SR04 센서의 회로도가 포함되어 있습니다. 저도 처음 IoT 프로젝트를 시작할 때 회로도 참고 자료가 없어 많이 헤맸는데, 이 자료로 바로 연결 방법을 확인할 수 있습니다.

이 자료가 도움되는 이유

  1. 바로 사용 가능: Fritzing 파일로 제공되어 바로 회로도에 활용 가능
  2. 핀맵 정리: 각 센서별 ESP32 핀 연결 정보를 한눈에 파악
  3. 다양한 센서 포함: IoT 프로젝트에서 자주 쓰는 4가지 센서 회로도 수록
  4. 공식 문서 링크: 각 센서 데이터시트 및 라이브러리 링크 포함

어떤 Quest에 유용한가요?

  • ✅ Quest 1 - 하드웨어 설정: 센서 선택 및 기본 연결 방법 참고
  • ✅ Quest 2 - 센서 연동: 핀맵과 회로도를 바탕으로 실제 연결 구현
  • ✅ Quest 3 - 데이터 수집: 여러 센서를 동시에 연결할 때 핀 충돌 방지

⚠️ 참고할 때 주의사항

  • 전압 주의: ESP32는 3.3V 로직이므로 5V 센서 연결 시 레벨 시프터 필요
  • I2C 주소 충돌: BMP280과 MPU6050 함께 쓸 때 주소 설정 확인 필요
  • Fritzing 버전: Fritzing 0.9.10 이상 버전에서 열기 권장

📌 자료 소개

Quest 제출 시 필요한 항목들을 정리한 Notion 템플릿입니다.

프로젝트 개요, 기술 스택, 진행 과정, 결과물을 체계적으로 정리할 수 있습니다. Quest 채점 기준에 맞춰 모든 필수 항목이 포함되어 있어, 처음 제출하는 분들도 빠짐없이 정리할 수 있습니다.

이 템플릿이 도움되는 이유

  1. 채점 기준 반영: Quest 평가 항목을 모두 커버하는 구조
  2. 바로 복사해서 사용: Notion 링크 클릭 → 복제 → 바로 작성 시작
  3. 시각적 구성: 심사위원이 빠르게 내용을 파악할 수 있는 레이아웃
  4. 예시 포함: 각 섹션마다 작성 예시가 있어 막막하지 않음

추천 사용 순서

  1. Notion 템플릿 복제
  2. 프로젝트 개요부터 순서대로 작성
  3. 결과물 스크린샷/영상 첨부
  4. 제출 전 체크리스트 확인

📌 자료 소개

보안 카메라 프로젝트에서 사용한 객체 추적 알고리즘 코드입니다.

SORT, DeepSORT 알고리즘을 적용한 실전 예제를 주석과 함께 공유합니다. 라즈베리파이 4 환경에서 실제 동작 검증을 완료한 코드입니다.

이 코드가 도움되는 이유

  1. 실제 프로젝트에서 검증: 보안 카메라 프로젝트에서 실제로 사용하고 검증한 코드
  2. 두 가지 알고리즘 제공: 간단한 SORT부터 정확도 높은 DeepSORT까지 선택 가능
  3. 상세 주석: 각 함수와 파라미터에 설명 주석 포함
  4. 라즈베리파이 최적화: ARM 환경에서 최대 성능을 내도록 최적화

⚠️ 사용 시 주의사항

  • Python 버전: Python 3.8 이상 권장
  • OpenCV 버전: OpenCV 4.5 이상 필요
  • DeepSORT 의존성: torch, torchvision 설치 필요 (용량 큼)
  • 라즈베리파이: DeepSORT는 Pi 4 이상에서만 실용적인 fps 가능
