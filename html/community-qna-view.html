ESP32에서 MQTT 브로커 연결이 자꾸 끊기는 현상 해결 방법

Quest 2: 센서 데이터 수집 및 전송
IoT 혁신 챌린지 2026
#ESP32 #MQTT #IoT #네트워크
어떤 작업을 하고 있나요?
Current work context

Quest 2에서 ESP32와 MQTT 브로커를 연결하는 작업을 하고 있습니다. AWS IoT Core를 사용 중이며, 센서 데이터를 5초마다 전송해야 하는 상황입니다.

어떤 문제가 있나요?
Problem description
Wi-Fi 연결은 정상인데 MQTT 브로커로의 연결이 5-10분마다 자동으로 끊깁니다. 연결이 끊길 때 Error code -2가 계속 발생하며, 재연결 시도는 성공하지만 다시 끊기는 현상이 반복됩니다.
무엇을 시도했나요?
What I've tried
1. Keep-alive 시간을 기본 15초에서 60초로 늘려봤습니다 2. QoS 레벨을 0, 1, 2로 각각 시도해봤습니다 3. WiFi 재연결 코드를 추가했습니다 4. MQTT 브로커 로그를 확인했지만 특별한 오류가 없었습니다 5. 다른 MQTT 클라이언트(PC)로 테스트했을 때는 문제가 없었습니다
어떤 도움을 받고 싶나요?
What help is needed
연결이 끊기는 근본적인 원인을 찾고 싶습니다. ESP32 설정이나 코드에서 놓친 부분이 있는지 확인 부탁드립니다. 특히 전력 관리나 WiFi 설정 관련해서 조언해주시면 감사하겠습니다.
추가 정보 및 코드
Additional details

Quest 2 진행 중인데 ESP32에서 MQTT 브로커 연결이 계속 끊깁니다.

현재 상황:
• MQTT 브로커: AWS IoT Core
• 연결은 되지만 5-10분 사이에 랜덤하게 끊김
• Error code -2 발생

void reconnect() {
  while (!client.connected()) {
    if (client.connect("ESP32Client")) {
      client.subscribe("home/sensor");
    } else { delay(5000); }
  }
}

박엔지니어 채택된 답변 1시간 전
WiFi.setSleep(false) 설정을 추가해보세요. ESP32는 기본적으로 Modem Sleep 모드가 활성화되어 있어서 MQTT keepalive와 충돌이 납니다.

PubSubClient의 MQTT_KEEPALIVE 값도 낮춰보시고, loop() 함수 내에서 client.loop()를 더 자주 호출하는 것도 도움이 됩니다.
최
최개발 45분 전
WiFi.setAutoReconnect(true) 설정도 추가해보세요. 저도 비슷한 증상이 있었는데 이걸로 해결됐습니다.

#OpenCV #Python #최적화 #라즈베리파이
어떤 작업을 하고 있나요?
Current work context

Raspberry Pi 4에서 OpenCV로 실시간 객체 추적을 구현 중입니다. SORT 알고리즘을 사용하고 있으며 Quest 2 목표인 실시간 영상 처리(20fps 이상)를 달성해야 합니다.

어떤 문제가 있나요?
Problem description
현재 5-8fps 정도 나오는데 최소 20fps는 되어야 합니다. CPU 사용률이 95%에 달하고 있습니다.
무엇을 시도했나요?
What I've tried
1. 이미지 해상도를 640x480으로 낮춰봤습니다 2. 프레임 스킵(2프레임마다 처리)을 적용해봤습니다 3. OpenCV 빌드 시 NEON 최적화 옵션을 활성화했습니다
어떤 도움을 받고 싶나요?
What help is needed
라즈베리파이에서 OpenCV 실시간 처리 성능을 높이는 방법이 알고 싶습니다. 멀티프로세싱이나 GPU 가속을 사용하는 방법도 궁금합니다.
추가 정보 및 코드
Additional details

Raspberry Pi 4에서 OpenCV로 실시간 객체 추적을 구현 중입니다.

현재 환경:
• Raspberry Pi 4 (4GB RAM)
• Python 3.9, OpenCV 4.7
• SORT 알고리즘 사용

Quest 3: AI 모델 배포 및 테스트
IoT 혁신 챌린지 2026
#TensorFlow #라즈베리파이 #AI #TFLite
어떤 작업을 하고 있나요?
Current work context

PC에서 TensorFlow로 학습한 얼굴 인식 모델을 라즈베리파이에 배포하려고 합니다. 모델을 TFLite로 변환하는 것까지는 완료했습니다.

어떤 문제가 있나요?
Problem description
TFLite 모델을 라즈베리파이에서 실행할 때 "RuntimeError: Failed to load delegate from libedgetpu.so.1" 오류가 발생합니다. EdgeTPU를 사용하지 않아도 같은 오류가 납니다.
무엇을 시도했나요?
What I've tried
1. pip install tflite-runtime 설치 시도 2. tensorflow 전체를 설치해봤지만 ARM 호환 오류 발생 3. libedgetpu 라이브러리 수동 설치 시도 4. Python 버전을 3.9에서 3.8로 낮춰봤습니다
어떤 도움을 받고 싶나요?
What help is needed
EdgeTPU 없이 TFLite 모델만으로 라즈베리파이에서 실행하는 방법이 알고 싶습니다. 올바른 패키지 설치 방법과 추론 코드 예제도 부탁드립니다.
추가 정보 및 코드
Additional details

PC에서 TensorFlow로 학습한 모델을 TFLite로 변환했는데, 라즈베리파이에서 실행할 때 오류가 발생합니다.

오류 메시지:
RuntimeError: Failed to load delegate from libedgetpu.so.1

답변 2
해결됨
김
김AI 채택된 답변 2시간 전
EdgeTPU를 사용하지 않는다면 일반 tflite_runtime 패키지를 설치하세요: pip install tflite-runtime

인터프리터 초기화 시 experimental_delegates 파라미터가 있다면 해당 줄을 삭제하거나 try-except로 감싸세요.
