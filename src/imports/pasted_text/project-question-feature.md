메이크 2.0에서 “프로젝트 진행 중 질문하기” 기능을 구현한 화면을 만들어 주세요.

이 기능은 독립적인 게시판 새 글 작성이 아니라,
사용자가 프로젝트를 작성하거나 Quest를 진행하는 도중에
현재 문맥을 유지한 채 질문을 생성하는 구조여야 합니다.

핵심 방향:
- 질문은 프로젝트와 분리된 글이 아니라, 현재 작업 중인 프로젝트와 연결된 질문이어야 함
- 사용자가 프로젝트 작성 흐름을 끊지 않고 바로 질문할 수 있어야 함
- 질문 글에는 현재 프로젝트 정보와 Quest 정보가 자동으로 연결되어야 함

만들어야 할 화면 구조는 아래와 같습니다.

1. 프로젝트 작성/편집 화면 안의 커뮤니티 액션 영역
- 프로젝트 작성 또는 Quest 입력 화면 안에 아래 버튼들이 보여야 함
  - 질문하기
  - 진행 공유
  - 팀원 찾기
  - 자료 공유
- 이 중 “질문하기”가 가장 눈에 띄게 배치
- 버튼 위치는 우측 패널 또는 상단 액션 바 형태
- 사용자가 지금 프로젝트를 작성 중이라는 문맥이 유지되어야 함

2. 질문하기 버튼을 누르면 열리는 질문 작성 UI
- 전체 페이지 이동보다 모달 또는 우측 슬라이드 패널 형태 추천
- 제목: 질문하기
- 부제: 현재 프로젝트와 연결된 질문을 등록합니다

3. 질문 작성 UI 안에 자동으로 채워지는 정보 영역
이 영역은 읽기 전용 또는 자동 연결 정보처럼 보여야 함
- 연결된 프로젝트명
- 프로젝트 링크 또는 프로젝트 카드 미리보기
- 현재 Quest 단계
- 기술 태그
- 콘테스트명(콘테스트 프로젝트일 경우)
- 프로젝트 상태(예: 진행중)

이 영역은 “이 질문이 어떤 프로젝트와 연결되는지” 바로 이해되게 해 주세요.

4. 질문 입력 영역
아래 항목이 보이도록 구성
- 질문 제목
- 질문 유형 선택
  - 기술 문제
  - 구현 방법
  - 설계 고민
  - 제출 관련
  - 피드백 요청
- 본문 입력 영역
  - 지금 어떤 작업을 하고 있나요?
  - 어떤 문제가 있나요?
  - 무엇을 시도해 보았나요?
  - 어떤 도움을 받고 싶나요?

질문 입력창은 빈 텍스트박스 하나가 아니라,
질문 품질을 높이는 가이드형 폼으로 보여야 합니다.

5. 첨부 영역
- 이미지 첨부
- 코드 스니펫 첨부
- GitHub 링크 추가
- 참고 링크 추가

6. 하단 액션 버튼
- 질문 등록
- 임시 저장
- 취소

7. 질문 등록 후 연결 구조가 보이는 안내
질문 등록 후에는 아래 구조가 사용자에게 보이거나 안내되어야 함
- 이 질문은 커뮤니티 Q&A에 등록됩니다
- 동시에 현재 프로젝트 상세에도 연결됩니다
- My Make에서도 확인할 수 있습니다

8. 프로젝트 상세 안의 연결된 질문 섹션도 함께 구성
프로젝트 상세 페이지 안에 아래 섹션이 보이게 해 주세요
- 제목: 이 프로젝트와 연결된 질문
- 질문 카드 예시 2~3개
- 새 답변 수
- 해결 여부
- 질문하기 버튼
- 전체 질문 보기 버튼

질문 카드에는 아래 정보가 보여야 합니다
- 질문 제목
- 질문 유형
- 연결된 Quest
- 작성자
- 답변 수
- 댓글 수
- 최근 활동 시간
- 해결 여부

9. 알림 흐름도 반영
사용자가 나중에 답변을 받았을 때 아래 두 곳에서 알 수 있어야 합니다
- 프로젝트 페이지 안의 “프로젝트 활동” 또는 “새 답변” 영역
- My Make의 알림 센터

즉 이 화면은 단순 글쓰기 기능이 아니라,
프로젝트 → 질문 생성 → 커뮤니티 연결 → 답변 반응 → 프로젝트 안에서 다시 확인
의 흐름이 느껴지게 구성해 주세요.

디자인 방향:
- 한국어 UI
- 현재 Make 2.0 스타일 유지
- 게시판처럼 보이지 않게
- 프로젝트 중심의 생산적인 커뮤니티 도구처럼 보이게
- 메이커/엔지니어가 실제로 작업 중 바로 도움을 요청하는 UX처럼 보여야 함
