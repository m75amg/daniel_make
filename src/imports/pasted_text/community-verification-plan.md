현재 Make 2.0의 커뮤니티 구조에서 아래 4가지 항목이 완성되어 있습니다.

- 최근 질문
- 최근 진행공유
- 최근 팀원찾기
- 최근 자료공유

이제 검증이 필요합니다.

검증 목적:
“커뮤니티 도움받기” 카드에서 작성하는 각 글 작성 페이지의 입력 항목들이
커뮤니티 리스트 카드와 상세 페이지에 정확하게 매칭되어 노출되는지 확인하고,
누락되거나 잘못 매칭된 부분이 있으면 수정해 주세요.

검증 대상:
1. 질문하기
2. 진행공유
3. 팀원찾기
4. 자료공유

검증 방식:
각 유형별로 아래 3가지를 비교해 주세요.

A. 작성 페이지의 입력 항목
B. 커뮤니티 리스트 카드에서 보이는 항목
C. 커뮤니티 상세 페이지에서 보이는 항목

반드시 아래 형식으로 검토해 주세요.
- 어떤 입력 항목이 있는지
- 그 입력 항목이 리스트 카드에 어떻게 축약/요약되어 보여야 하는지
- 그 입력 항목이 상세 페이지에 어떻게 전체 노출되어야 하는지
- 현재 누락된 항목은 무엇인지
- 현재 잘못 매칭된 항목은 무엇인지
- 수정이 필요한 항목은 무엇인지

유형별 기준은 아래와 같습니다.

1. 질문하기
작성 페이지 입력 항목 예:
- 연결 프로젝트
- 현재 Quest
- 기술 태그
- 질문 제목
- 질문 유형
- 어떤 작업을 하고 있는지
- 어떤 문제가 있는지
- 무엇을 시도했는지
- 어떤 도움을 원하는지
- 첨부 이미지 / 코드 / GitHub / 링크

검증 포인트:
- 리스트 카드에는 질문 제목, 질문 유형, 연결 프로젝트, Quest, 답변 수, 해결 상태가 보여야 함
- 상세 페이지에는 위 본문 항목이 모두 구조적으로 보여야 함
- 답변/댓글 구조가 질문 유형에 맞게 노출되어야 함

2. 진행공유
작성 페이지 입력 항목 예:
- 연결 프로젝트
- 현재 Quest
- 기술 태그
- 공유 제목
- 이번 단계에서 한 일
- 현재까지 완료한 내용
- 막힌 점 또는 고민
- 다음에 할 일
- 이미지 / 영상 / 링크 첨부

검증 포인트:
- 리스트 카드에는 공유 제목, 진행 요약, 연결 프로젝트, Quest, 반응 수가 보여야 함
- 상세 페이지에는 “이번에 한 일 / 완료한 내용 / 막힌 점 / 다음 할 일”이 모두 보여야 함
- 질문 상세 페이지처럼 보이면 안 됨

3. 팀원찾기
작성 페이지 입력 항목 예:
- 연결 프로젝트
- 현재 Quest
- 기술 태그
- 모집 제목
- 프로젝트 한줄 설명
- 현재 진행 단계
- 필요한 도움
- 모집 역할
- 협업 방식
- 예상 기간
- 연락 방법

검증 포인트:
- 리스트 카드에는 모집 제목, 필요한 역할, 프로젝트명, 모집 상태, 참여 요청 수가 보여야 함
- 상세 페이지에는 역할 / 협업 방식 / 연락 방법 / 현재 단계가 분명히 보여야 함
- 질문 상세 페이지처럼 보이면 안 됨

4. 자료공유
작성 페이지 입력 항목 예:
- 연결 프로젝트
- 현재 Quest
- 기술 태그
- 자료 제목
- 자료 유형
- 자료 설명
- 왜 도움이 되는지
- 어떤 Quest/단계에 유용한지
- 링크 / 파일 첨부

검증 포인트:
- 리스트 카드에는 자료 제목, 자료 유형, 연결 프로젝트, 관련 Quest, 요약 설명이 보여야 함
- 상세 페이지에는 자료 설명, 활용 단계, 링크/파일 구조가 보여야 함
- 질문 상세 페이지처럼 보이면 안 됨

중요:
- 각 유형별로 “작성 페이지 → 리스트 카드 → 상세 페이지”의 정보 흐름이 일관되어야 합니다
- 같은 유형인데 리스트와 상세가 질문 템플릿으로 통일되어 있으면 안 됩니다
- 각 유형별 목적에 맞는 UI와 정보 구조가 유지되어야 합니다

작업 요청:
1. 4개 유형 각각에 대해 필드 매칭을 검증
2. 누락/오류/잘못된 매칭을 정리
3. 필요한 경우 리스트 카드와 상세 페이지를 수정
4. 최종적으로 4개 유형 모두 입력 내용과 화면 노출이 일관되게 맞도록 정리

Do not only summarize the verification.
Actually compare the fields and update the UI where the mapping is incorrect or missing.
